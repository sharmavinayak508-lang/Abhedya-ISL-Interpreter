# 🧏 Abhedya – AI Sign Language Interpreter

> An AI-powered accessibility solution designed to help deaf and hard-of-hearing students understand technical education.

## 🎯 Problem

Deaf and hard-of-hearing students can face difficulties understanding classroom lectures, especially when teachers use technical terminology such as algorithms, networking, programming, and other domain-specific concepts.

## 💡 Our Solution

**Abhedya** is a digital sign-language interpretation platform designed for technical education.

It converts classroom communication into accessible visual/sign-language assistance and provides tools for learning, vocabulary, lecture analysis, and accessibility.

## 🚀 Key Features

- 🎙️ Live Lecture Interpreter
- 🤟 ISL / Fingerspelling Support
- 🧑‍💻 Technical Vocabulary
- 🧠 AI Lecture Analysis
- 🧑‍🎨 Sign Avatar
- 📚 Lecture Slides
- 💬 Ask ISL
- 📷 Camera & Recognition Prototype
- 📊 Learning & Analytics
- ♿ Accessibility Features

## ⚙️ How It Works

Teacher Speech
↓
Speech-to-Text
↓
Technical Term Detection
↓
ISL / Fingerspelling Mapping
↓
Visual Sign / Avatar
↓
Student Understanding
