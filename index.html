Know Your Sign Name

A playful ISL-inspired name generator based on your name's initial.

A

Real Sign Names are a meaningful tradition, usually given to a person by members of the Deaf community — not generated by an app. This is a lighthearted starting point, not a substitute for that. It also doesn't analyze any photo: it works from the letters you type, which is more transparent about what's actually happening than a "facial analysis" would be for a browser demo.

About this project

What's real, what's mocked, and what's next.

What it does

ISL Lecture Interpreter listens to spoken lecture audio (or a scripted demo), matches recognized words against a sign vocabulary, and displays a live sign feed alongside a simplified concept summary — aimed at making classroom lectures more accessible in real time.

What's real

The speech recognition, word-by-word gloss matching, fingerspelling fallback for unrecognized technical terms, and the live transcript highlighting all run genuinely in the browser using the Web Speech API. The Lessons quizzes are graded live, per-topic scores persist in the browser, and the spelling tool builds real letter sequences from anything typed. Ask ISL matches your question against a small built-in set and calls out real dictionary signs found in the answer. Photo Insights computes genuine pixel-level brightness and color stats from whatever you upload, entirely on-device.

What's mocked

The current avatar is a visual prototype; validated ISL sign videos/motion data are still required for production-grade signing accuracy. Dictionary, lesson and alphabet entries use emoji and styled text as placeholders rather than photographed or filmed ISL handshapes. Ask ISL answers a fixed question set rather than reasoning freely, and Photo Insights doesn't yet recognize objects, landmarks or diagrams — that needs a real vision model. Sign Name is a lighthearted generator based on typed letters, not facial analysis, and isn't a substitute for a Sign Name given by the Deaf community. Login is a local demo gate with no real backend.

Roadmap

Next: Replace emoji glyphs and alphabet text with real ISL sign clips or filmed handshapes
Then: Connect Ask ISL and Photo Insights to real language and vision AI models
Later: Map spoken-English word order to ISL grammar, expand the dictionary and lesson library, and add offline/low-bandwidth mode
